À propos de StreamBox

Une seule boîte à outils pour streamer, au lieu d’installer cent outils différents : overlays, bot, alertes, subathon, musique… Gratuite, sans publicité, et ouverte à tous.

Open source

Le code de StreamBox est public et libre, sous licence GNU AGPL-3.0. En clair :

  • tout le monde peut utiliser StreamBox, gratuitement, et lire son code ;
  • tout le monde peut l’améliorer et proposer ses modifications ;
  • une version modifiée, même mise en ligne sur un autre site, doit rester open source sous la même licence. Les améliorations profitent ainsi toujours à tout le monde.

Voir le code sur GitHub

Toute contribution est la bienvenue

Pas besoin de savoir coder pour aider :

Proposer une idéeUn outil qui manque, une option, une amélioration ? Décris-la, même en deux phrases.Proposer
Signaler un bugQuelque chose ne marche pas ? Dis-nous ce que tu as fait et ce qui s’est passé (une capture aide beaucoup).Signaler
Contribuer au codeCorrige un bug ou ajoute un outil, puis ouvre une pull request sur le dépôt principal. Le guide est dans CONTRIBUTING.md.Lire le guide
Plutôt une suggestion qu’un fork. Tu as le droit de forker StreamBox : c’est la licence qui le veut. Mais si tu veux une fonction, propose-la ou contribue directement ici. Une seule version commune, c’est une version mieux maintenue et plus sûre, et chaque amélioration profite à tous les streamers. Plusieurs copies qui divergent, c’est des bugs corrigés à moitié et du travail fait en double.
