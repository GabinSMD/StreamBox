Automatisations

« Quand il se passe ça, fais ça. » Un raid change de scène, un abo active un filtre, une récompense de points de chaîne affiche une source pendant 10 secondes… Les automatisations tournent dans OBS, dans une source navigateur invisible.

1. Ajoute la source dans OBS

Dans OBS : Sources → + → Navigateur, colle ce lien (taille 300 × 200, la source reste invisible). Pour voir le journal des automatisations, ajoute aussi le lien avec le journal comme dock : Docks → Docks de navigateur personnalisés.

Le mot de passe d’OBS et les jetons viennent de Mon compte : renseigne « Mot de passe du serveur WebSocket d’OBS » pour les actions OBS. Les messages du chat utilisent les permissions du bot.
